# MODERN USA & CANADA WATER ENGINEERING

### Currently minimal in App

| | | | | | | | | Invention | Date | Location | Description | Significance | | | | | |
|-----------|------|----------|-------------|-------------|
| | | | | | | | **Erie Canal** | 1825 | New York | 584 km artificial waterway connecting Great Lakes to Atlantic. 83 locks overcoming 173 m elevation. Transformed American commerce and westward expansion. Called "Clinton's Ditch" by skeptics — became the most successful infrastructure project in early American history. | Most important canal in American history | | | | | |
| | | | | | | | **Croton Aqueduct (New York)** | 1842 | New York | 66 km gravity aqueduct from Croton River to Manhattan. First major urban water supply in the United States. | | | | | | | | **Chicago River Reversal** | 1900 | Illinois | The flow of the Chicago River was reversed — away from Lake Michigan (the water supply) and toward the Mississippi basin — to carry sewage away from the city. Required excavating the 45 km Chicago Sanitary and Ship Canal. One of the most dramatic water engineering feats in American history. | Most dramatic river engineering in American history — reversed a river | | | | | |
| | | | | | | | **Los Angeles Aqueduct** | 1913 | California | 375 km gravity-fed aqueduct from Owens Valley to LA. Designed by William Mulholland. Effectively "stole" water from the Owens Valley — draining Owens Lake dry. The most controversial water project in American history. Inspired the film Chinatown. | Most controversial water project in American history | | | | | |
| | | | | | | | **Hoover Dam** | 1936 | Nevada/Arizona | Already in app. 221 m tall concrete arch-gravity dam. Created Lake Mead — largest reservoir in USA. 2,080 MW. Changed Western American development. 96 construction deaths officially recorded (higher actual). | Most iconic dam in the world | | | | | |
| | | | | | | | **Tennessee Valley Authority (TVA)** | 1933 | Tennessee Valley | 29 dams, navigation locks, flood control, and hydropower across the Tennessee Valley. First integrated river basin management authority. Lifted one of America's poorest regions out of poverty. Model for river basin authorities worldwide. | First integrated river basin authority — global model | | | | | |
| | | | | | | | **Central Arizona Project** | 1973–1993 | Arizona | 541 km canal lifting Colorado River water 825 m to central and southern Arizona. 14 pump stations. Largest and most expensive aqueduct in the US. Delivers 1.8 km³/year. | Largest aqueduct in the United States | | | | | |
| | | | | | | | **California State Water Project** | 1960–1973 | California | Largest state-built water infrastructure in the US. 34 storage facilities, 20 pumping plants, 5 power plants, 1,100 km of canals. Pumps water over the Tehachapi Mountains — the highest single water lift in the world (588 m at Edmonston Pumping Plant). | Highest water lift in the world | | | | | |
| | | | | | | | **St. Lawrence Seaway** | 1954–1959 | USA/Canada | 3,700 km navigable waterway from the Atlantic to Lake Superior. 15 locks overcoming 75 m elevation. Joint USA-Canada project. Created 10,000+ MW of hydropower. Transformed Great Lakes shipping. | Largest binational waterway in North America | | | | | |
| | | | | | | | **James Bay Project** | 1971–1996 | Quebec, Canada | Massive hydroelectric project diverting rivers flowing into James Bay. 215 dams and dikes, 11,000 MW installed capacity. Flooded 11,500 km² of Cree territory. Canada's largest construction project. Deeply controversial — Cree opposition led to environmental reforms. | Largest construction project in Canadian history — and most controversial | | | | | |
| | | | | | | | **Canadian Oil Sands Tailings Ponds** | 1960s–Present | Alberta | Tailings ponds from oil sands extraction covering 220+ km². Contain toxic water that cannot be returned to the environment. One of the largest water contamination challenges on Earth. Visible from space. | Largest industrial water contamination in North America | | | | | |
| | | | | | | | **Milwaukee Deep Tunnel** | 1993 | Wisconsin | Deep rock tunnel system storing combined sewage during storms to prevent overflow to Lake Michigan. 32 km of tunnels, 130+ m deep, storing 2.1 billion liters. Model for CSO control nationwide. | Major deep tunnel CSO control system | | | | | |
| | | | | | | | **NYC Delaware Aqueduct Repair** | 2023 | New York | Repair of the Delaware Aqueduct — the longest tunnel in the world (137 km). Built 1937–1944. Leaking 130 million liters/day. Bypass tunnel drilled 180 m deep beneath the Hudson River. Cost $1 billion+. | Repair of the world's longest water tunnel | | | | | |
