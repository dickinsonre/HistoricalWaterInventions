## Aboriginal Australia — Expanded (65,000 BCE – Present)

### Currently in App: 3 inventions
### Should Have: 12+

The Aboriginal Australians managed water across an entire continent for 65,000 years — the longest continuous water management tradition on Earth. Your current 3 inventions barely scratch the surface.

| | | | | | Invention | Date | Location | Description | Significance | | | |
|-----------|------|----------|-------------|-------------|
| | | | | **Brewarrina Fish Traps (Baiame's Ngunnhu)** | 40,000+ BCE | NSW | Already in app. Stone weir structures across the Barwon River creating pools and channels to trap fish. Extends over 500 m. Possibly the oldest human-engineered structure on Earth. | Oldest known water engineering structure in the world | | | |
| | | | | **Gnamma Holes** | 10,000+ BCE | Western Australia | Already in app. Natural rock depressions enlarged and modified to collect and store rainwater. Some sealed with stone caps to reduce evaporation. Aboriginal people memorized the locations of thousands across the desert. | Distributed desert water storage network maintained for millennia | | | |
| | | | | **Aboriginal Wells (Native Wells)** | 40,000+ BCE | Multiple | Already in app. Hand-dug wells accessing shallow aquifers. Some wells in Western Australia reach 3+ meters depth. Maintained and concealed across generations. | Among the oldest water wells on Earth | | | |
| | | | | **Fire-Stick Farming for Water Management** | 65,000 BCE onwards | Continent-wide | Systematic burning to manage vegetation, which in turn managed water flow, soil moisture, and groundwater recharge. Burns created mosaic landscapes with diverse water retention characteristics. Changed the hydrology of an entire continent. | Largest-scale landscape hydrology management in human history | | | |
| | | | | **Songline Water Navigation** | 65,000 BCE onwards | Continent-wide | Oral mapping system encoding the locations of water sources across thousands of kilometers of desert. Songlines (dreaming tracks) contain precise hydrological information — spring locations, seasonal water availability, well depths — embedded in songs, stories, and ceremonies. | Most sophisticated oral hydrological database ever created | | | |
| | | | | **Desert Soak Wells (Yuu)** | 10,000+ BCE | Western Desert | Shallow wells dug into dry riverbeds to access subsurface flow. Covered with branches and sand to reduce evaporation and prevent animal contamination. Locations known only to initiated adults. | Secret water infrastructure — concealment as engineering | | | |
| | | | | **Budj Bim Eel Aquaculture System** | 6,600 BCE | Victoria | Volcanic stone channels, weirs, and ponds managing water flow to trap and farm eels. Over 100 km² of engineered wetland. UNESCO World Heritage. One of the oldest aquaculture systems in the world. Predates agriculture in Mesopotamia. | Oldest known aquaculture system in the world — UNESCO site | | | |
| | | | | **Toolondo Aboriginal Canal System** | Pre-contact | Victoria | Stone-lined channels connecting wetlands and directing water flow across the Western District. Some channels extend several kilometers. | Pre-contact canal engineering in southeastern Australia | | | |
| | | | | **Dampier Peninsula Tidal Fish Traps** | 1000+ BCE | Western Australia | Stone walls built in intertidal zones trapping fish as tides recede. Multiple configurations for different tidal conditions. Some walls extend hundreds of meters. | Tidal water engineering for fisheries | | | |
| | | | | **Murray-Darling Bark Canoe Navigation** | 10,000+ BCE | Southeast Australia | Bark canoes (nawi) for river navigation requiring deep knowledge of river currents, seasonal water levels, and channel conditions across Australia's largest river system. | River navigation knowledge spanning 2,500+ km of waterways | | | |
| | | | | **Aboriginal Water Sharing Protocols** | 65,000 BCE onwards | Continent-wide | Complex customary law governing water access, sharing obligations, and resource management. Different nations had different protocols depending on environment. Violations could result in severe sanctions. | Oldest continuous water governance system on Earth | | | |
| | | | | **Rainwater Tree Collection** | Traditional | Arid regions | Specific tree species known to collect and channel rainwater down trunks into root hollows. Aboriginal people maintained these trees and harvested water from root cavities. | Biological water harvesting | | | |
| | | | | **Sand Filtering for Water Purification** | Traditional | Multiple | Digging shallow wells near but not in waterbodies — using sand and soil as natural filters. Water seeping through ground to the well was cleaner than surface water. | Natural filtration water purification | | | |
| | | | | **Desert Dew Collection** | Traditional | Central Australia | Collecting morning dew from grass and leaves using absorbent materials (animal skins, plant fiber), then wringing water into containers. | Atmospheric water harvesting | | | |
