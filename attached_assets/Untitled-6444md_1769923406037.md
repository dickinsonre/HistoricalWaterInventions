# Water Inventions: India (Post-Indus), Southeast Asia, Pre-Roman Europe, Philippines & Tibet

Excellent additions for your Historical Mystery platform! These regions have remarkable and often overlooked water engineering traditions.

## 🇮🇳 INDIA (Post-Indus Valley Civilizations)

### Maurya & Gupta Periods (322 BCE - 550 CE)

| | Invention | Period | Description | Engineering Significance | |
|-----------|--------|-------------|-------------------------|
| | **Sudarshana Lake** | 322 BCE | Massive artificial reservoir in Gujarat, built by Chandragupta Maurya | One of earliest large-scale dam projects; repaired multiple times over 800 years | |
| | **Arthashastra Water Laws** | ~300 BCE | Kautilya's treatise included detailed irrigation regulations | First codified water rights and tank management systems | |
| | **Grand Anicut (Kallanai)** | 2nd century CE | Stone dam across Kaveri River, Tamil Nadu | World's oldest water-diversion structure still in use; 329m long | |

### South Indian Kingdoms (300 BCE - 1300 CE)

| | Invention | Period | Description | Engineering Significance | |
|-----------|--------|-------------|-------------------------|
| | **Eri (Tank) System** | 300 BCE onwards | Interconnected cascade tank systems in Tamil Nadu | Up to 39,000 tanks linked; gravity-fed irrigation network | |
| | **Sluice Gates (Talaivaasal)** | 500 CE | Stone sluice gates with multiple outlets at different heights | Allowed selective water release for different crop stages | |
| | **Ooranis** | Ancient | Village ponds for drinking water, separate from irrigation tanks | Social water management with community ownership | |
| | **Korambu** | Medieval | Temporary earthen bunds across streams | Seasonal water harvesting for single-crop irrigation | |

### Medieval India (600 - 1600 CE)

| | Invention | Period | Description | Engineering Significance | |
|-----------|--------|-------------|-------------------------|
| | **Stepwells (Vav/Baoli)** | 600 CE onwards | Multi-story wells with stepped access (Gujarat, Rajasthan) | Combined water storage with cooling; architectural marvels | |
| | **Kund/Kundi** | 800 CE | Circular underground cisterns with steps | Rainwater harvesting in arid regions | |
| | **Johads** | Medieval | Crescent-shaped earthen check dams | Groundwater recharge; still revived today by Rajendra Singh | |
| | **Phad System** | 15th century | Community-managed diversion weir system in Maharashtra | Equitable water distribution with time-based rotation | |
| | **Ahar-Pyne** | Medieval | Flood water harvesting system in Bihar | Channels (pyne) directing monsoon floods to storage (ahar) | |
| | **Zabo** | Traditional | Impounded runoff from forest + paddy in Nagaland | Integrated watershed management | |
| | **Bamboo Drip Irrigation** | Traditional | Meghalaya's bamboo pipe irrigation for betel leaf | 18-20 liters/minute over hundreds of meters using only bamboo | |

## 🇹🇭 SIAM (Thailand)

### Sukhothai & Ayutthaya Kingdoms (1238 - 1767 CE)

| | Invention | Period | Description | Engineering Significance | |
|-----------|--------|-------------|-------------------------|
| | **Khlong (Canal) Networks** | 13th century | Extensive canal systems for transport and irrigation | Bangkok called "Venice of the East"; 1,682 km of canals | |
| | **Muang Fai** | Traditional | Community weir system in Northern Thailand | Bamboo/stone weirs with communal water allocation rules | |
| | **Nong (Reservoirs)** | Ancient | Large rectangular reservoirs near temples | Combined religious and agricultural water supply | |
| | **Pratuu Nam** | Medieval | Wooden sluice gates for canal flow control | Controlled flooding of rice paddies | |
| | **Floating Houses (Ruan Pae)** | 15th century | Houses on bamboo rafts in flood-prone areas | Adaptive architecture for monsoon flooding | |
| | **Sra (Tanks)** | Ayutthaya period | Urban water storage linked to monasteries | Temple-managed public water supply | |

### Unique Thai Innovations

| | Invention | Description | Engineering Significance | |
|-----------|-------------|-------------------------|
| | **Rahat (Water Wheel)** | Buffalo-powered Persian-style wheel | Lifted water 2-3m for irrigation; introduced via trade | |
| | **Fish-Rice Paddy Integration** | Combined aquaculture with wet rice | Natural pest control; additional protein source | |
| | **Royal Rainmaking** | Modern (1955) cloud seeding program | King Bhumibol's innovation; now used regionally | |

## 🇰🇭 CAMBODIA (Khmer Empire)

### Angkorian Period (802 - 1431 CE)

| | Invention | Period | Description | Engineering Significance | |
|-----------|--------|-------------|-------------------------|
| | **Baray System** | 9th-12th century | Massive rectangular reservoirs (8km x 2km) | West Baray held 56 million cubic meters | |
| | **Srah (Urban Tanks)** | 9th century | Smaller urban reservoirs within Angkor | Neighborhood water supply and microclimate cooling | |
| | **Moat Systems** | 12th century | 200m-wide moats around temples | Defensive, spiritual, and water storage functions | |
| | **Canals (Praek)** | 802 CE onwards | 1000+ km connecting barays to rice fields | Gravity-fed distribution; up to 8km long | |
| | **Spillway Cascades** | 11th century | Sandstone overflow structures with carved nagas | Combined hydraulic function with religious art | |
| | **Trap Bridges** | Medieval | Stone bridges with water control function | Acted as small dams regulating downstream flow | |

### Pre-Angkorian (Funan & Chenla)

| | Invention | Period | Description | Engineering Significance | |
|-----------|--------|-------------|-------------------------|
| | **Circular Moated Sites** | 400 BCE | Round earthworks with water channels in Mekong Delta | Earliest hydraulic engineering in Southeast Asia | |
| | **Raised Field Systems** | 200 CE | Elevated planting beds in floodplains | Flood-adapted agriculture; similar to Mexican chinampas | |
