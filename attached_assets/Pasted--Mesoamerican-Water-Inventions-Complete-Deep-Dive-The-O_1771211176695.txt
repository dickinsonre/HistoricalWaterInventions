# OLMEC (1500–400 BCE)

## Currently not in App — Critical Gap

The Olmec are the "mother culture" of Mesoamerica. Your search results specifically mention their water engineering, yet they have no entry. This is the biggest Mesoamerican gap in the app.

| | | | | | | | Invention | Date | Location | Description | Significance | | | |  |
|-----------|------|----------|-------------|-------------|
| | | | | | | **San Lorenzo Basalt Drain System** | 1200–900 BCE | San Lorenzo, Veracruz | Elaborate system of basalt stone drains atop the San Lorenzo plateau. U-shaped basalt troughs carved from massive stone blocks with precise dimensions — each block identical — lined up side by side to create water channels. The drain system connected to stone-lined reservoirs and ritual pools. Required transporting basalt blocks from mountains 60+ km away. | Oldest engineered water drainage system in Mesoamerica — and among the most sophisticated of its age anywhere | | | |  |
| | | | | | | **San Lorenzo Aqueduct** | 1200–900 BCE | San Lorenzo | Stone-lined aqueduct bringing water from distant springs to the hilltop settlement. The Olmec "laboriously carved massive pieces of stone into identical blocks with a trough on one end; they then lined these blocks up side by side to create a channel for water to flow." Required precision stone-cutting and surveying. | First aqueduct in the Americas | | | |  |
| | | | | | | **San Lorenzo Ritual Water Pool** | 1200–900 BCE | San Lorenzo | A masonry sunken court fitted with a drain that could be "easily filled and emptied of water to serve as a pool for ritual use." Four explicit representations of the Olmec maize god surround the pool. Water rituals central to Olmec religion. | Earliest known ritual water architecture in the Americas | | | |  |
| | | | | | | **El Manatí Sacred Spring Complex** | 1600–1200 BCE | Southern Veracruz | Sacred spring site at the foot of Cerro Manatí hill. | | | | | | | **Olmec Vulcanized Rubber for Water Use** | 1600–1200 BCE | Gulf Coast | The Olmec created vulcanized rubber by mixing latex from rubber trees (Castilla elastica) with juice from morning glory vines. | | | | | | | **La Venta Pyramid & Water Management** | 900–400 BCE | Tabasco | The first pyramid in Mesoamerica (Complex C at La Venta) required water management during construction and use. Channels directed water around and through the ceremonial complex. | Water management for the first Mesoamerican pyramid | | | |  |
| | | | | | | **La Venta Massive Stone Offering Drainage** | 900–400 BCE | Tabasco | Thousands of serpentine blocks arranged in elaborate patterns and buried in pits with sophisticated drainage. | | | | | | | **Olmec Water Cosmology System** | 1500–400 BCE | Gulf Coast | The Olmec developed the fundamental Mesoamerican water cosmology: rain gods (precursors to Tlaloc/Chaak), sacred mountains containing water, caves as water-world entrances, and the water-maize-fertility connection. # MAYA — Classic Period (250–900 CE)

| | | | | | | | Invention | Date | Location | Description | Significance | | | |  |
|-----------|------|----------|-------------|-------------|
| | | | | | | **Tikal Reservoir System** | 250–900 CE | Guatemala | Six major reservoirs holding estimated 900,000 m³ of water. Palace Reservoir, Temple Reservoir, Hidden Reservoir, and Corriental Reservoir were the largest. Positioned to catch maximum runoff from plastered plaza surfaces. | | | | | | | **Tikal Water Filtration (Corriental)** | 250–900 CE | Guatemala | Quartz sand and zeolite filtration system discovered at Tikal's Corriental reservoir. The only known pressurized water system in pre-Columbian Americas. | Only known pressurized water in pre-Columbian Americas | | | |  |
| | | | | | | **Palenque Nine-Aqueduct System** | 600–800 CE | Chiapas | Not just one aqueduct — Palenque had nine mapped subterranean aqueducts managing 56 springs within the city. | | | | | | | **Maya Chultun (Underground Cistern)** | 600 BCE–900 CE | Multiple sites | Bottle-shaped underground cisterns carved into limestone bedrock. | | | | | | | **Copán Drainage System** | 400–800 CE | Honduras | Elaborate stone-lined drainage beneath the Acropolis. Multiple channels directing water through the monumental core. | | | | | | | **Quiriguá Flood Management** | 400–810 CE | Guatemala | Located on the Motagua River floodplain — one of the most flood-prone locations of any major Maya city. | | | | | | | **Kaminaljuyú Canal Irrigation** | 400 BCE–200 CE | Guatemala (Highland) | Highland Maya city with canal irrigation from Lake Miraflores. | | | | | | | **Puuc Region Chultun Network** | 600–1000 CE | Yucatán | The Puuc hills of Yucatán have no surface water — no rivers, lakes, or springs. | | | | | | | **Uxmal Water Collection** | 700–1000 CE | Yucatán | Uxmal's Nunnery Quadrangle and Governor's Palace positioned to maximize rainwater collection. | | | | | | | **Dos Pilas Defensive Water** | 761 CE | Guatemala | After military defeat, the Maya at Dos Pilas dismantled their own temples to build defensive walls and used water as a defensive feature — flooding approaches and channeling attackers into kill zones. | | | | | | | **Maya Water Lily Symbolism-Engineering** | Classic Period | Multiple | The water lily (Nymphaea ampla) appears throughout Maya art and was cultivated in reservoirs.
