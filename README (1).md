## About

Historical Water Inventions is an interactive web application that maps the world's most significant water engineering innovations across civilizations and millennia. Each invention is placed in its geographic and historical context, making the deep roots of modern hydraulic engineering tangible and explorable.

This project is part of the [SWMM5.org](https://swmm5.org) educational ecosystem — a collection of tools and resources dedicated to preserving and sharing water engineering knowledge.

## What's Inside

The app covers **seven categories** of water technology spanning six continents:

| Category | Example Inventions |
|---|---|
| **Water Transport Systems** | Persian Qanats, Roman Aqueducts, Cloaca Maxima |
| **Water Lifting Devices** | Shaduf, Archimedes Screw, Noria Waterwheels |
| **Measurement & Timekeeping** | Nilometers, Water Clocks (Clepsydra) |
| **Urban Sanitation** | Indus Valley Drainage, Great Bath of Mohenjo-daro, Minoan Plumbing |
| **Water Purification** | Egyptian Alum Treatment, Sanskrit Purification Methods |
| **Regional Innovations** | Nazca Puquios, Maya Reservoirs, Pre-Incan Amunas |
| **Irrigation Systems** | Egyptian Basin Irrigation, Mesopotamian Canals |

## Features

- **Interactive World Map** — Browse inventions by geographic location
- **Timeline Navigation** — Explore innovations from 6000 BCE to the modern era
- **Detailed Entries** — Each invention includes its civilization, approximate date, description, and key engineering features
- **Unique Hydraulic Model Count** — Tracks the number of hydraulic simulation models referenced across the app
- **Responsive Design** — Works on desktop, tablet, and mobile

## Quick Start

The app is built to run on [Replit](https://replit.com). To run locally:

```bash
# Clone the repository
git clone https://github.com/dickinsonre/HistoricalWaterInventions.git
cd HistoricalWaterInventions

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Why This Exists

Every modern sewer pipe, treatment plant, and stormwater model stands on thousands of years of engineering ingenuity. The Persians tunneled qanats through mountains to move water by gravity alone — the same principle behind every gravity sewer designed today. Archimedes' screw still powers modern industrial pumps. Roman aqueduct gradients anticipated the hydraulic grade line calculations we run in SWMM and InfoWorks ICM.

This app was built to make that lineage visible and interactive — because understanding where water engineering came from helps us appreciate where it's going.
